# Atlas Vector Search Setup (E·OVR)

Follow these steps to enable Atlas Vector Search for incident embeddings.

1. In Atlas UI, go to **Browse Collections** → `eovr` → `incidents` → **Search Indexes** → **Create Index** → **JSON Editor**.
2. Paste this index definition:

```json
{
  "mappings": {
    "dynamic": false,
    "fields": {
      "ai_metadata.embedding_vector": {
        "dimensions": 1536,
        "similarity": "cosine",
        "type": "knnVector"
      }
    }
  }
}
```

3. The index remains empty until embeddings are generated by calling `POST /ai/classify/batch`.
4. `1536` dimensions matches:
   - OpenAI `text-embedding-3-small`
   - Anthropic Embeddings API
   - Gemini `embedding-001`
5. This index cannot be created via the Motor driver; create it in Atlas UI.
6. You can delete and recreate the index without data loss.
